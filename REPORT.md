## Rebase vs Merge

- Merge preserves the original branch history and creates a merge commit when needed.
- Rebase reapplies feature commits on top of the latest target branch.
- Merge provides a clear record of integration points between branches.
- Rebase creates a cleaner linear history but changes commit hashes.
